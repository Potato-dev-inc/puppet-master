Phone, v3 premium detail

Still monochrome. Tap around the phone. Every agent, question and output is example data.

  1. Dot-matrix state glyphs. A 3×3 grid per state: pulse, sweep, spiral, X, check. Replaces the dots, rings and "!" (inventory 6, colour-only status).
  2. Waiting counter in Doto. "02 waiting" sits by the large title, the one display moment on this screen.
  3. Sliding Needs you / All control. The pill springs between segments and the list cross-fades with blur. Replaces the single flat inbox (inventory 3.4).
  4. Terminal · Receipt switch. The receipt is a summary of the turn, not just a second scroll (inventory 3.5).
  5. Thinking shimmers and cycles. The state text says what the agent is doing, not a static label (inventory 3.5).
  6. Auto-growing composer. One to five lines, Steer or Follow-up toggle changes the placeholder, send fills only when there is text (inventory 3.5, 44px box).
  7. Spawn sequence, not "Loading agent…". A 5×5 loader and a log show the real steps for about 2.5s (inventory 3.5).
  8. All clear state. An empty Needs you shows a quiet grid and a 5×5 idle loader instead of nothing (inventory 3.4).
  9. Undo toast and live timers. Answers confirm with Undo; elapsed times tick (inventory 3.4 had no answer feedback).
  10. Theme switch in Menu. Sun and moon rotate and set the theme for both light and dark tokens. Reduced motion shows static patterns.

Not covered: ⌘K palette and keycaps (no keyboard on the phone), wordmark slice effect (desktop sidebar only), pairing and setup screens. Doto is loaded from Google Fonts, not next/font. Not tested in a browser.
