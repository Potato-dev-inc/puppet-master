Phone, monochrome v2

Tap around the phone. Every agent, question and output is example data.

  1. Push navigation, not a tab bar. Agents is a root list; an agent slides in from the right. Fixes the top tab strip that scrolled sideways (inventory 3.3).
  2. Needs you comes first, with the question. Each row shows the actual prompt and Yes / No inline. Previously an amber border and no question (inventory 3.4).
  3. State is a glyph and weight, not colour. Solid dot, spinner, breathing dots, hollow ring, "!" and check. Removes the colour-only dots (inventory 6).
  4. Monochrome terminal. Diffs use a left rule and weight, not red and green (inventory 6, ANSI mapping).
  5. Question sits above the composer. Keys opens from a keyboard-glyph button; Ctrl latch shows a pressed key (inventory 3.5, bug 7).
  6. Sheets with grabbers and swipe-down. New agent and Menu are inset lists; disabled agents state why (inventory 3.6).
  7. Unpair asks first, in an action sheet. Replaces the immediate unpair and native dialogs (inventory 3.1, 6).
  8. Connection in plain words. "Connected · 42 ms" replaces RTT and typing-echo jargon (inventory 6).

Not covered: pairing and setup screens, the legacy PWA, size-claim and nudge behaviour, hidden-input mode, the full 16-state set (eight shown). Not tested in a browser.
