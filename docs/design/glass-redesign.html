Frosted glass over a stage of live agents

Three redesign proposals for the desktop Home screen, the Settings window and the phone PWA. They borrow the bento grids, big-number tiles and pill navigation from the Muzli 2025 dashboard roundup, and Apple's materials: translucent layers, a specular top edge, system status colours, grouped inset lists and a Solid fallback for Reduce Transparency. All agent and pane data is example data.

Replaces the hero band

The marketing headline and decorative mini panes go. The space goes to live pane tiles that show the last terminal line and the classifier state from pane-state.ts.

“Needs you” first

Approval prompts get their own card with Approve and Deny, wired to answer_prompt. Attention panes get an orange halo so they read at a glance.

KPIs that move

Four tiles replace the static Bridge, Panes, Orchestrator and Model cards. The pane tile becomes a status bar, and Preload status lands on the Home screen.

Glass rules

Wallpaper sits at z −1, cards use backdrop-filter: blur(28px) saturate(180%) and a 1px inner highlight. Solid mode turns all of that off.

Proposal 2 · Settings window

Settings: System Settings layout

22 flat tabs become four groups with icon tiles. Planned tabs fold away under “Coming later”, so the live settings are easier to find. Click the sidebar to try it.

Puppet Masterv0.1.4 · dev build

Groups, not a 22-item list

SETTINGS_TABS gains a group and an icon. The planned: true tabs collapse into one disclosure instead of showing a red “Not implemented” badge on every row.

Inset grouped rows

SettingBlock and SettingToggle become rows in one glass list per group: label and hint on the left, control on the right, with hairline dividers.

Native-feeling controls

Theme becomes a segmented control with System added. Toggles become iOS-style switches. Preload counts become steppers with status dots that show warm agents.

Reduce transparency

Appearance gets glass intensity and Reduce transparency settings, and the app honours prefers-reduced-transparency.

Proposal 3 · Mobile PWA

Phone: Agent tabs and Keys sheet

The same material on the phone: a floating glass tab bar, cards for each agent, and the Keys panel as a bottom sheet with one-tap answers.
